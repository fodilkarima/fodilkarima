
# 🔎 Veille métier et technologique

Dans le cadre de ma formation et de mon développement professionnel en Data Analysis,
je réalise une veille régulière afin de suivre l'évolution des outils, méthodes
et compétences du métier.

## 🎯 Objectifs de ma veille

- suivre les évolutions de Python, SQL et Power BI ;
- approfondir dbt, Snowflake et les pratiques Data Engineering ;
- suivre les évolutions du Machine Learning et de l'IA ;
- identifier les compétences recherchées pour les postes de Data Analyst ;
- améliorer mes pratiques de qualité et de documentation des données.

## 📰 Sources suivies

À compléter uniquement avec les sources que j'utilise réellement.

- Documentation officielle Python / Pandas
- Documentation Microsoft Power BI
- Documentation dbt
- Documentation Snowflake
- Blogs, articles et ressources spécialisées Data
- Offres d'emploi Data Analyst pour suivre les compétences recherchées

## 🔄 Méthode

Je consulte régulièrement plusieurs sources et je sélectionne les informations
selon leur pertinence pour le métier de Data Analyst, leur fiabilité et leur
utilité dans mes projets.

## ✅ Critères de sélection

- fiabilité de la source ;
- actualité de l'information ;
- pertinence pour le métier ;
- possibilité d'application concrète ;
- intérêt pour mes projets ou mon évolution professionnelle.

## 💡 Mise en pratique

Cette veille m'a notamment permis d'approfondir :

- la structuration des modèles dbt ;
- la modélisation en étoile dans Power BI ;
- les bonnes pratiques de nettoyage et de contrôle qualité ;
- la comparaison de plusieurs modèles de Machine Learning ;
- la documentation et la reproductibilité des analyses.
